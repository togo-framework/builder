### The stack — non-negotiable, it is what togo is

| Layer | What it is |
|-------|-----------|
| Kernel | togo microkernel. Plugins self-register via `init()` + `togo.RegisterProviderFunc(name, priority, fn)`. Nothing is wired by hand in `main`. |
| HTTP | chi router, mounted by providers |
| Data access | **sqlc** — typed Go from `*.sql` query files. togo *is* the ORM; hand-written SQL outside a query file is banned. |
| Schema | **Atlas**, applied with `togo migrate`. Service code never creates tables — no `CREATE TABLE IF NOT EXISTS` at runtime, ever (see the no-direct-DDL rule). |
| Codegen | `togo generate` runs sqlc → gqlgen → OpenAPI. Output is `*.gen.go` — never hand-edited (see the service-boundaries rule). |
| Frontend | `web/` — TanStack React. It talks to `{{api_base}}` over HTTP and **never opens a database connection** (see the no-DB-client-in-web rule). |
| Authz | togo auth. `Can()` is an **exact string match** — `permissions=["*"]` denies everything, it does not grant everything. |

## What this repo is NOT

- **Not a fork of togo.** togo is a dependency. If a fix belongs in the framework, say so and park it — do not vendor-patch the kernel here.
- **Not a place for ad-hoc SQL.** No `db.Exec("CREATE TABLE ...")`, no inline query strings, no `IF NOT EXISTS` bootstrapping from service code. Schema changes are migrations, full stop.
- **Not a monolith with a frontend bolted on.** `web/` is a client of `{{api_base}}`, not a second backend.
- **Not a scratchpad.** Generated files, migrations, and `.claude/` are load-bearing artifacts, not disposable output.
